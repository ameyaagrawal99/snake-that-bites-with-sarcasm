# Snake That Bites with Sarcasm

Snake That Bites with Sarcasm is a playful browser app built around classic Snake gameplay, layered with sarcastic live commentary and companion planning tools for faculty salary and hiring scenarios. It mixes a game surface with comparison utilities in a single web experience.

## What it includes

- Classic Snake gameplay with keyboard and mobile controls
- Dynamic sarcastic commentary based on in-game events
- High-score tracking in the browser
- Faculty salary calculator and comparison views
- Bulk hiring scenario planning for academic roles

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run check
```
